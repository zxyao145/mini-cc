# 收件箱默认未读筛选设计

## 目标

收件箱在 URL 未显式指定阅读状态时，默认只显示未读文章。用户通过筛选控件选择的阅读状态继续生效；其他视图的缺省行为不变。

## 方案

在 `parseLibraryQuery` 解析状态筛选时，仅当阅读状态参数缺失且视图为收件箱时，将状态设为 `['unread']`。URL 显式提供的 `status` 值优先，包括显式的多状态筛选。序列化逻辑保持现状，因此收件箱默认筛选可由现有查询序列化写为 `status=unread`；其他视图不会继承该默认值。

仅调整查询解析及其单元测试，不改变 API、持久化数据或阅读状态写入行为。

## 验收

- 收件箱 URL 未带 `status` 时，查询状态为未读。
- 收件箱 URL 显式指定阅读状态时，保留该筛选。
- 非收件箱视图未指定状态时仍不筛选阅读状态。
